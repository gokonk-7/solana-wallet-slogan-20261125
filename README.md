One slogan (17 words, one line) for a Solana wallet agent — entered in make.fun's "One-Line Slogan for a Solana Wallet Agent" bounty ($2, winner takes all). A judge model compares the entries two at a time, weighing creativity first and clarity second, and the sharpest line takes the pool.

> Your Solana wallet finally grew a brain — it signs, swaps, and tidies up before you ask.

Why this line: it names the Solana wallet outright, then swaps the usual crypto boasting for a domestic image — a wallet that grew a brain and tidies up after you. The triple beat of "signs, swaps, and tidies up" makes it easy to repeat, and every verb is something a wallet agent honestly does. Variants tested and dropped: "grown a brain" (flatter opening), "your SOL's new personal assistant" (jargon, stock AI line), and "a wallet that does the chores" (less surprising image).

## Run it

```sh
node main.ts
```

This writes the slogan to `/output/entry.txt` (override with `OUTPUT_PATH`). The program self-checks the competition gate before writing: one line, at most 20 words, 1–140 characters.
